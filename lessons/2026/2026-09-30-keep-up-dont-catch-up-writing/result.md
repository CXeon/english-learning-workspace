## 构思与修订

- 内容按“精力有限导致落后 → 补齐遗漏会形成双重负担 → 完成当日课程的轻量版本 → 保持连续性”展开。
- 内容修订轮明确了工作与家庭事务后精力有限的通用情境，并补充了计划中断后重新开始需要更多努力的结果。
- 语言修订轮重点处理了 `after + -ing`、主格代词 `they` 和指代前文的 `This`。
- 学习者课后澄清：原意是工作尚未做完时主动停下，而不是完成工作；因此终稿使用 `stopping work for the day`。结尾句中的输入偏差是键入错误，不作为知识缺口记录。

## 终稿

> A learner often starts studying after stopping work for the day and spending time with their family, so they may fall behind because their energy is limited. It can be difficult to catch up on everything because the learner has to complete missed lessons while following the current plan. Instead, the learner should make a lighter version of the plan but still complete the core tasks. This helps them keep up with the current plan. If a plan is interrupted, restarting it takes more effort.
