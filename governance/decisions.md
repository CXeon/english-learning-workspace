# 教学与系统决策日志

## 2026-08-25：阅读课与听力课分离

- 变化：工作日阅读课与听力课默认分开。
- 原因：一次课程混合阅读、听力和音频技术排障，超出计划时长。
- 影响：听力使用上一节已读材料；音频必须在课前验证。

## 2026-08-26：仓库成为跨 Agent 的唯一事实来源

- 变化：教学规则、当前状态、课程结果和审核规则改由本仓库维护。
- 原因：额度中断、上下文压缩和模型替换不应破坏学习连续性。
- 影响：所有 Agent 须从 `START_HERE.md` 开始；默认只本地提交，不自行推送。

## 2026-08-27：音频资产不得阻塞或缩短学习

- 变化：听力课只有在音频完成生成、公开审核、登记、远程上传与播放验证后才能进入开课校验；课程结束时若把听力列为下一节，必须同步把音频准备完成。学习者持续授权公开审核通过的原创课程文档和 AI 合成音频默认推送到远程仓库。
- 原因：音频来源记录错误和审核滞后曾导致计划中的听力被替换为轻量回忆，影响正常学习。
- 影响：音频问题在正式学习计时外解决；若当次无法完成，改上同等时长的完整非音频课程，不得缩短、取消或提前结束学习。OpenAI ChatGPT/Codex 应用内置默认合成语音可在记录来源、确认不含真人或克隆声音、注明 AI 生成并验证可播放后公开迁移并推送。
